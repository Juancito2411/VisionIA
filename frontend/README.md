# VISION AI — Frontend

Cliente web React + TypeScript + Vite.

```powershell
npm install
Copy-Item .env.example .env
npm run dev
```

Configura `VITE_API_URL` en `.env` para apuntar a la API FastAPI. Valor local predeterminado: `http://127.0.0.1:8000/api/v1`.

Validación de compilación: `npm run build`.
